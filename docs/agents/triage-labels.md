# Triage Labels

The skills use five standard triage roles. This file maps those roles to the label strings in the issue tracker of this repo.

| Label in mattpocock/skills | Label in our tracker | Meaning                                         |
| -------------------------- | -------------------- | ----------------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer must examine this issue            |
| `needs-info`               | `needs-info`         | The issue waits for more information            |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified. An agent can do it on its own  |
| `ready-for-human`          | `ready-for-human`    | A person must do it                             |
| `wontfix`                  | `wontfix`            | We will not do it                               |

When a skill names a role (for example "apply the AFK-ready triage label"), use the label string for that role from this table.

To use different labels, change the "Label in our tracker" column.
